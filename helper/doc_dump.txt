P003 [Heading 3]: 1.1 Background
P004 [normal]: Transmission lines carry bulk electrical power over long distances and are exposed to weather, lightning, vegetation, equipment failure, and human error. Faults on these lines (short circuits between phases or to ground) produce large currents and voltage sags that can damage equipment and cause outages if not cleared quickly. Protection systems must therefore detect a fault, identify its type, and isolate the faulted section within a few cycles.
P005 [normal]: Common transmission line faults are:
P006 [normal]: Single line-to-ground (LG): A-G, B-G, C-G
P007 [normal]: Line-to-line (LL): A-B, B-C, A-C
P008 [normal]: Double line-to-ground (LLG): AB-G, BC-G, AC-G
P009 [normal]: Three-phase (LLL) and three-phase-to-ground (LLLG)
P010 [normal]: Conventional distance and overcurrent relays rely on fixed thresholds and impedance settings, which can misoperate under varying fault resistance, fault location, source strength and loading. With digital protection (numerical relays, IEDs), data-driven classifiers can learn fault signatures directly from voltage and current measurements.

P013 [normal]: Faster and more accurate fault-type identification improves relay selectivity and single-pole tripping decisions.

P016 [normal]: SVMs work well on small-to-medium tabular datasets, handle non-linear boundaries through kernels, and are lightweight enough for a digital relay module.

P069 [Heading 2]: 6. Proposed Method
P070 [Heading 3]: 6.1 Support Vector Machine
P071 [normal]: An SVM finds the hyperplane that maximizes the margin between classes. For non-linearly separable data it uses a kernel function to map inputs into a higher-dimensional space. With the RBF kernel, K(x, x') = exp(-gamma * ||x - x'||^2). The parameter C controls the trade-off between a wide margin and misclassification of training points, and gamma controls how far the influence of a single training sample reaches. Multi-class classification is done using the one-vs-one (scikit-learn SVC default) or one-vs-rest strategy.

P079 [normal]: import pandas as pd, numpy as np, joblib
import matplotlib.pyplot as plt, seaborn as sns
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.preprocessing import StandardScaler, LabelEncoder
from sklearn.pipeline import Pipeline
from sklearn.svm import SVC
from sklearn.metrics import classification_report, confusion_matrix, accuracy_score

# 1. Load data
df = pd.read_csv('fault_data.csv')          # [EDIT file name]
print(df.shape); print(df.info()); print(df.describe())

# 2. Clean
df = df.drop_duplicates().dropna()
LABEL = 'Fault_Type'                          # [EDIT label column]
X = df.drop(columns=[LABEL]); y = df[LABEL]
le = LabelEncoder(); y_enc = le.fit_transform(y)

# 3. EDA
sns.countplot(x=y); plt.title('Class distribution'); plt.show()
sns.heatmap(X.corr(), cmap='coolwarm'); plt.show()

# 4. Split (70/15/15 stratified)
X_tr, X_tmp, y_tr, y_tmp = train_test_split(X, y_enc, test_size=0.30, stratify=y_enc, random_state=42)
X_val, X_te, y_val, y_te = train_test_split(X_tmp, y_tmp, test_size=0.50, stratify=y_tmp, random_state=42)

# 5. Pipeline + tuning
pipe = Pipeline([('scaler', StandardScaler()), ('svm', SVC())])
grid = {'svm__kernel': ['linear', 'rbf'],
        'svm__C': [0.1, 1, 10, 100],
        'svm__gamma': ['scale', 0.01, 0.1, 1]}
gs = GridSearchCV(pipe, grid, cv=StratifiedKFold(5, shuffle=True, random_state=42),
                  scoring='f1_macro', n_jobs=-1)
gs.fit(X_tr, y_tr)
print('Best params:', gs.best_params_)

# 6. Validate and test
best = gs.best_estimator_
print('Validation acc:', accuracy_score(y_val, best.predict(X_val)))
y_pred = best.predict(X_te)
print('Test acc:', accuracy_score(y_te, y_pred))
print(classification_report(y_te, y_pred, target_names=le.classes_))
cm = confusion_matrix(y_te, y_pred)
sns.heatmap(cm, annot=True, fmt='d', xticklabels=le.classes_, yticklabels=le.classes_)
plt.xlabel('Predicted'); plt.ylabel('Actual'); plt.show()

# 7. Prototype module
joblib.dump({'model': best, 'encoder': le}, 'fault_classifier.pkl')

def classify_fault(sample):
    """sample: list/array of features in the same order as training columns"""
    bundle = joblib.load('fault_classifier.pkl')
    pred = bundle['model'].predict(np.array(sample).reshape(1, -1))
    return bundle['encoder'].inverse_transform(pred)[0]
